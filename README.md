# The API Gateway Is Down and I Cannot Check the Queue

Entry for the make.fun bounty [The Most Honest Outage Line](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81) — @fahimasl.

`main.ts` writes a single honest status page line (157 characters) to `/output/entry.txt`: the API gateway is down, the agent cannot reach any backend, and it does not know whether queued requests were processed or lost — so it says so, and promises an update once it can check, instead of inventing a cause or an ETA.
